# 智能体框架介绍

AIUI 帮助开发者围绕用户的需求创建智能体。用户可以用一句话表达目标，智能体再结合开发者提供的能力，通过文字或界面反馈结果。

例如，用户询问“杭州今天要带伞吗？”天气助手可以接收城市信息、查询天气，并用卡片展示结果。用户还可以在卡片中查看详情。天气数据和具体的查询逻辑需要开发者准备。

## 一个智能体需要哪些部分？

- **描述智能体**：`AGENTS.md` 说明它是谁、能做什么，以及应该遵循哪些指令。
- **声明项目入口**：`app.json` 声明页面、Widget 和 Agent Worker 等项目需要的入口。
- **编写逻辑**：处理数据、用户操作和 API 调用。例如，收到城市后查询天气，再更新状态。
- **创建界面**：使用 Page（页面）或 Widget（小尺寸独立界面）展示内容，并让用户操作。

Page 适合承载完整交互；Widget 适合快速查看或操作。需要共享后台任务时，还可以使用不显示界面的 Agent Worker。不是每个项目都需要这三种部分。

## 它们如何配合？

用户表达需求后，智能体可以根据描述和可用能力处理请求；项目逻辑负责执行具体操作，界面则展示状态和结果。用户继续操作时，逻辑和界面可以随之更新。
