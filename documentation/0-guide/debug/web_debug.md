# AIUI 智能体网页端模拟调试

在 Studio 打开项目，用浏览器检查首屏和交互。如果还没有项目，登录 Rokid 账号后选择**对话创建**。首次使用时启用内置的 `aiui-dev` 技能，再让 AIUI CODING 创建一个带按钮的页面。

## 1. 网页端模拟调试

打开**真机模拟**，选择**效果预览**。等首屏加载后，用模拟器提供的输入、镜腿操作和光照设置测试智能体。

![AIUI Studio 的浏览器预览与模拟操作](../../image/quickstart/9.png)

## 2. 开发者自测

在预览中完成主要任务并返回。重复操作，如果某一步失败，查看控制台和网络日志。切换光照设置，检查文字和状态提示是否仍然清晰。

提审前，在眼镜上验证启动、语音、手势、网络以及智能体用到的设备能力。可以[通过 Studio 调试](./real_device_debug.md)，也可以[使用命令行调试](/AIUI/guide/debug-cli_device_debug)。
