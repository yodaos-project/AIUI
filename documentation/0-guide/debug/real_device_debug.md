# AIUI Studio 真机调试

将在 AIUI Studio 保存的版本同步到眼镜，并确认智能体能打开。开始前，请在 Studio 打开项目，并在 Rokid AI App 中连接 Rokid 眼镜。要通过 ADB 安装本地项目，请参阅[命令行真机调试](/AIUI/guide/debug-cli_device_debug)。

## 1. AIX 打包并保存资料

1. 打开**构建与提审**，执行 **AIX 打包**。
2. 等待上传完成。如果上传失败，按提示修复后重新打包。
3. 保存智能体资料。Studio 完成打包并保存版本后，手机 App 才能下载新版本。版本号由 Studio 生成。

![构建与提审页签中的 AIX 打包入口](../../image/quickstart/10.jpg)

## 2. 真机调试

1. 在 Rokid AI App 中进入**设置 → 开发者选项 → AIUI**。
2. 点击**更新眼镜资源包**，等到 App 提示**智能体资源包下载成功**。

![手机 App 中的眼镜资源包更新入口](../../image/quickstart/11.png)

3. 用语音说出智能体名称并打开它，检查首屏是否包含刚才的改动。

![在 Rokid 眼镜上打开智能体](../../image/quickstart/12.png)

如果没看到改动，检查 Studio 是否已上传并保存最新版本，再更新一次眼镜资源包。

## 3. 开发者自测

在眼镜上从头走一遍智能体的主要流程。

- 确认首屏能加载，任务可以完成，也能正常返回。
- 测试智能体实际使用的输入方式，例如语音、摄像头或镜腿操作。
- 换几种光照环境，检查文字、图标和状态提示是否看得清。
- 重复运行主要流程，检查遇到异常输入或断网时页面如何提示，并查看控制台或网络日志中有无未处理的错误。

验证通过后，[准备提审资料](../bundle/publish.md)。
