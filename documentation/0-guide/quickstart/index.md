# 快速开始

为 Rokid 眼镜创建一个页面，先在浏览器中查看效果。在本地开发需要 Node.js 20 或更高版本及 npm。

## 创建并预览第一个智能体

1. [创建并预览页面](../../4-tutorials/getting-started/create-first-agent.md)。创建项目，在浏览器中确认页面显示 `Hello, AIUI!`。
2. [添加交互计数器](../../4-tutorials/interface/build-interactive-counter.md)。将按钮绑定到页面状态，在预览中确认计数会随点击更新。

如果想直接在浏览器中创建项目，可以[使用 AIUI Studio 开发](./quickstart.md)。
