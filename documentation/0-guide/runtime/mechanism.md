# 运行机制

用户打开一个智能体，页面显示内容；用户点击按钮，页面上的文字随之变化。这背后发生了什么？本篇通过一个简单页面，介绍 AIUI 如何加载页面、处理操作和更新界面。

## 一个页面由什么组成？

一个 AIUI 项目通常在 `app.json` 中声明页面，并在页面文件中编写数据、交互逻辑、界面结构和样式。运行时根据项目配置打开页面，再结合页面数据和界面结构生成用户看到的内容。

下面是一个 `.ink` 页面。初始文字是“你好”；用户点击按钮后，文字会变成“欢迎使用”。

```html
<script setup>
export default {
  data: {
    message: '你好'
  },

  showWelcome() {
    this.setData({ message: '欢迎使用' });
  }
};
</script>

<page>
  <view>{{ message }}</view>
  <button bindtap="showWelcome">点击我</button>
</page>
```

这里有三个关键部分：

- `data` 保存页面的数据；`message` 是页面最初要显示的文字。
- `{{ message }}` 把页面数据绑定到界面上。
- `bindtap="showWelcome"` 把按钮的点击操作关联到 `showWelcome` 函数。

## 从打开页面到更新界面

有了这个例子，就可以沿着用户的一次操作看整个过程：

1. **打开页面**：运行时加载页面定义和初始数据，并调用页面定义的相应生命周期函数。
2. **显示内容**：运行时根据页面结构、样式和数据生成界面，用户看到“你好”和按钮。
3. **处理点击**：用户点击按钮后，运行时将点击事件交给绑定的 `showWelcome` 函数。
4. **更新数据**：函数调用 `this.setData()`，将 `message` 改为“欢迎使用”。
5. **更新界面**：运行时根据新的数据更新关联的界面内容，用户看到新的文字。

页面逻辑负责处理数据和操作，界面结构负责描述显示内容；运行时把它们连接起来。可以把它们分别称为“逻辑”和“视图”，但不需要把它们理解成开发者必须分别启动的两个程序。

更新界面数据时，请使用 `this.setData()`；直接修改 `this.data` 不能保证界面更新。数据更新和屏幕实际呈现也不是同一个时刻，不要把调用 `setData()` 等同于新画面已经显示完成。

## 页面何时加载、显示和关闭？

页面从打开到关闭会经历不同阶段。你可以按需编写生命周期函数，让页面在合适的时机执行代码：

- `onLoad(query)`：页面加载时调用，可以读取打开页面时传入的参数。一个页面实例只调用一次。
- `onShow()`：页面显示或重新显示时调用。
- `onReady()`：页面初始界面的首帧实际呈现后调用，每个页面实例只调用一次。
- `onHide()`：页面隐藏时调用。
- `onUnload()`：页面卸载时调用，适合清理不再需要的资源。

例如，天气页面可以在 `onLoad(query)` 中读取城市，开始请求天气，并在返回结果后调用 `setData()` 更新页面。请求需要失败处理，页面也可以在等待时显示加载状态。

## 用户输入和其他任务如何处理？

按钮点击只是输入方式之一。页面也可以通过对应事件处理按键等操作；可用输入方式取决于设备和应用。网络请求、计时器等任务完成后，同样可以通过页面逻辑更新数据和界面。

如果项目需要不显示界面的共享后台任务，可以使用 **Agent Worker**。它有自己的用途和使用限制，不是每个智能体都需要；详情见 [Agent Worker 开发](/AIUI/framework/open-agent-format-agent-worker)。
