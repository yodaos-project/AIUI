# 智能体运行时

你写好了一个天气助手，用户打开它后，眼镜上出现天气页面。用户点击“查看详情”，页面随之显示更多信息。这些代码和界面是如何运行起来的？

它们需要一个运行环境。**AIUI 运行时**负责运行智能体的代码、展示界面，并帮助代码和用户操作配合起来。

## 运行时做些什么？

可以把智能体项目想象成一份准备好的方案：项目中描述了智能体、页面和交互逻辑；运行时则让这些内容在设备或开发环境中运行。

例如，当用户打开天气助手时，运行时会按照项目配置启动智能体，执行页面代码，并显示页面。用户操作后，页面逻辑可以处理操作、更新数据，界面再展示更新后的结果。

运行时还提供智能体可以使用的 API，让代码能够完成网络请求、存储数据等操作。具体能力和使用条件请以相应 API 文档为准。天气数据、业务逻辑和交互方式仍需要开发者在项目中准备。

## 一次交互是怎样发生的？

以天气页面上的“查看详情”按钮为例：

1. **显示界面**：运行时加载页面，用户看到天气信息和按钮。
2. **响应操作**：用户点击按钮，页面中对应的处理逻辑开始执行。
3. **更新结果**：页面逻辑更新数据，界面随之展示详情。

如果操作需要联网，页面还可以先显示加载状态，等请求完成后再展示结果；请求失败时，也可以提示用户重试。这样，用户能知道当前发生了什么。

想进一步了解页面数据和界面如何配合，可以继续阅读[运行机制](./mechanism.md)。

## 在哪里运行和调试？

开发时，你可以在 AIUI Studio 的网页模拟环境中预览界面和操作，方便快速检查修改效果。准备好后，再到 Rokid Glasses 等目标设备上测试真实的显示、交互和运行表现。

模拟预览和真机各有用途：预览方便快速迭代，最终体验需要在目标设备上验证。具体步骤和注意事项见[运行环境](./env.md)。

## 写代码时需要注意什么？

AIUI 使用 JavaScript 编写智能体的交互逻辑，也支持导入 TypeScript 模块。你可以使用常见的现代 JavaScript 语法，但不能假设浏览器中的所有 API 都可以直接使用；请查看对应的 API 文档确认。

同时，避免让同步代码长时间占用运行时，以免界面无法及时响应。常用语法、TypeScript 和执行时间限制见 [JavaScript 兼容性](./js.md)。
