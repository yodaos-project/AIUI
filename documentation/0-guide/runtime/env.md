# 运行环境

你可以在开发工具中预览 AIUI 智能体，也可以在 Rokid Glasses 等支持的设备上运行它。开发工具方便你快速修改和检查效果；真机则能帮助你确认用户实际看到和体验到的内容。

## 先在开发工具中预览

在 AIUI Studio 中，你可以编辑项目，并使用网页端模拟功能预览界面。模拟器可以帮助你检查页面显示、用户输入和镜腿操作等交互，也可以模拟不同光照条件下的显示效果。

例如，开发天气助手时，你可以先在预览中检查城市、温度和按钮是否按预期显示，再尝试模拟用户操作。

具体步骤请参阅[网页端模拟调试](../debug/web_debug.md)。Craft 也提供基于网页的项目编辑和预览能力。

## 为什么还要在真机上测试？

模拟预览能帮助你快速发现问题，但不能完全代表真实设备上的体验。完成基本功能后，请在目标设备上重点检查：

- **输入和设备能力**：语音、镜腿操作、摄像头或其他设备能力是否符合预期。模拟输入无法完全还原真实环境。
- **显示效果**：文字、布局和状态提示在眼镜中是否清晰、易读，不同设备的显示效果可能不同。
- **运行表现**：启动速度、动画和连续操作是否流畅。电脑上运行流畅的界面，在穿戴设备上可能表现不同。
- **真实使用条件**：网络变化、光照变化或连续操作时，智能体是否仍能正常使用。

最终的界面、交互和性能应以目标真机的测试结果为准。准备好后，可以按照 [AIUI Studio 真机调试](../debug/real_device_debug.md)操作。
